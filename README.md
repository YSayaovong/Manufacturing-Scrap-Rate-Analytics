# Manufacturing Scrap Rate Analytics
Synthetic manufacturing analysis with CSV facts, Python KPIs and PostgreSQL reporting views. Focus: trustworthy denominators, fact-table grain and reproducible reconciliation.

## Files
- `data/raw/`: production, defect-level scrap and dimension CSVs.
- `etl/refresh_kpis.py`: rebuilds `data/processed/` without a database.
- `analysis/visualize.py`: writes charts to `outputs/img/`.
- `sql/01_schema.sql`, `sql/03_views.sql`: PostgreSQL schema and corrected reporting views.
- [validate_metrics.py](validate_metrics.py): three regression cases and raw-data reconciliation using an in-memory SQLite compatibility adapter.
- [reports/reconciliation.json](reports/reconciliation.json): generated totals and source hashes.
- `outputs/csv/`, `assets/`: historical saved exports/screenshots, not regenerated by the commands below.
- `docs/ERD.md`: model notes.

## Reproduce checks
Python 3.10+; the validation script uses only the standard library:
```bash
python validate_metrics.py
```
Three cases check multiple defects per production record, scrap without production, and production without scrap. Raw-data checks include production-key uniqueness, orphan scrap keys, nonnegative quantities and daily/line reconciliation.

For the existing Python reporting workflow:
```bash
python -m pip install pandas numpy matplotlib
python etl/refresh_kpis.py
python analysis/visualize.py
```
Run from the repository root. Do not run both historical seed alternatives blindly; inspect `sql/02_seed.sql` and `sql/02_seed_data.sql` for their local import assumptions first.

## Reconciled sample result
350,111 units produced; 5,516 units scrapped; **1.5755% weighted overall scrap rate**. SQL daily and line totals agree with the CSV facts in the compatibility check. A mean of daily percentages is a different metric.

## Corrected aggregation
The former direct join of production to multiple defect rows counted the denominator repeatedly (611,914 units). Views now aggregate each fact separately before joining. Scrap-only groups remain visible. A rate with no positive production denominator is NULL, not zero.

The check adapts only CREATE OR REPLACE VIEW to SQLite CREATE VIEW. It tests aggregation logic, not PostgreSQL installation, permissions, import scripts or production deployment. Legacy SQL screenshots may show the earlier version and are not validation evidence.

## Analyst interpretation
Defect frequency identifies investigation priorities, not proven root cause. Exposure, product mix and operating context matter. Estimated costs are scenario values, not recoverable savings.
