# Explain the analysis
This is independent synthetic portfolio work developed with AI assistance. Learn the code and rerun the checks before presenting it. It is separate from Mechanical Designer employment.

1. Define the business question and record grain before showing a chart.
2. Open the source data and explain required fields, duplicate rules and join keys.
3. Run the validation command in the README and inspect its saved evidence.
4. Explain one data defect, its numerical effect, and the correction or review action.
5. Separate a recommendation from a proven root cause or realized saving.

## Connection to professional experience
The relevant foundation is BOM/configuration checks, Excel project tracking, SAP project/revision workflows, TDMS-to-Creo consistency checks and discrepancy investigation. These projects extend that context into analytical practice. Do not claim SQL/Python systems were built for the employer.

## Questions to practice
- Why can a join change a denominator?
- When is a repeated unit ID valid?
- Why is a weighted rate different from an average of percentages?
- Which conclusions does this sample not support?
